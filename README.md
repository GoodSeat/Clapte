## 1. Clapteの概要 ##

数式として認識可能な文字列がクリップボードにコピーされると、式中の単位を考慮して自動的に計算を実行し、その結果をバルーン表示します。

続けて、

 * バルーンをクリックする。
 * 同じ数式をコピーする。
 * ホットキーを押す。

のいずれかを実行することで、計算結果をクリップボードにコピーすることができます。

計算結果においては、単位を指定したり、有効数字を考慮することが可能です。

## 5. 使用方法 ##

#### クリップボード計算 ####
* Clapteを起動すると、システムに常駐し、クリップボードを監視します。
* 計算をするには、Clapteを起動した状態で、計算したい数式文字列をクリップボードにコピーします。
* クリップボード上の文字列が数式と認識され、かつ計算が成功した場合にのみ、計算結果がタスクトレイアイコンにバルーン表示されます。
* 計算結果がバルーン表示されている間に、以下のいずれかを実行することで、計算結果をクリップボードにコピーすることができます。
    * バルーンをクリックする。
    * 同じ数式をコピーする。
    * ホットキーを押す。
* 設定により、有効数字を考慮した計算が可能です（既定では無効です）。
* 数式の先頭に"[]"で括って単位を指定することで、計算結果の単位を指定できます。  
  `[m/s] 42.195km / (2h + 25min)`
* 一変数の方程式がコピーされた場合には、以下の要領で解を算出します。
  * 1～3次方程式に対しては代数的解法を用いて解きます。  
    `x^3 - 6x^2 + 11x - 6 = 0`
  * それ以外の方程式については、ニュートン法（式の微分に成功した場合）もしくはブレント法（式の微分に失敗した場合）を用いて、近似解を一つだけ求めます。  
    `x * sin(x) = 0.2`

#### 計算機 ####
* Ver2.0より、2分割のメモ帳形式の計算機を利用できるようになりました。
* Clapteのタスクトレイメニューから、計算機を起動することができます。
* 計算機では、変数や関数を容易に定義・利用して計算できます。
* 詳細については、計算機のヘルプを参照してください。

#### 2013.06.29 ver1.1.0 ####
* 追加
    * 方程式の解の算出機能を追加。
    * 定型文コピーによる定数／関数定義機能を追加。
    * システム定義関数に、round、mod関数を追加。
    * 複素数の累乗計算の処理を追加。
 
* 修正
    * タスクトレイメニューの「有効」状態が正しく反映されない不具合を修正。
    * sin、log等の関数でも、有効数字を考慮して計算を行うよう修正。
    * `2sin(π)`等の数式で、省略された関数前の乗算を認識しない不具合を修正。
    * 既存変数と同名の引数を用いたユーザー定義関数の定義編集時に、落ちる不具合を修正。
    * 負数において、有効桁数が一桁少なく表示される不具合を修正。
    * 計算機における以下の不具合を修正。
    * 単語の色分け機能有効時、環境により、色分け処理時に画面がちらつく。
    * 単語の色分け機能有効時、元に戻すの機能が正しく働かない。
    * `5kg/(2cm*3mm)` 等、分母が同次元異接頭辞の乗算から成る数式の計算時、応答が無くなる不具合を修正。
    * 計算時、ユーザー定義定数の定義が数値に置き換わってしまう不具合を修正。
