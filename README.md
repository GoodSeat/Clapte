## 1. Clapteの概要 ##

数式として認識可能な文字列がクリップボードにコピーされると、式中の単位を考慮して自動的に計算を実行し、その結果をバルーン表示します。

続けて、

 * バルーンをクリックする。
 * 同じ数式をコピーする。
 * ホットキーを押す。

のいずれかを実行することで、計算結果をクリップボードにコピーすることができます。

計算結果においては、単位を指定したり、有効数字を考慮することが可能です。

## 5. 使用方法 ##

* Clapteを起動すると、システムに常駐し、クリップボードを監視します。
* 計算をするには、Clapteを起動した状態で、計算したい数式文字列をクリップボードにコピーします。
* クリップボード上の文字列が数式と認識され、かつ計算が成功した場合にのみ、計算結果がタスクトレイアイコンにバルーン表示されます。
* 計算結果がバルーン表示されている間に、以下のいずれかを実行することで、計算結果をクリップボードにコピーすることができます。
    * バルーンをクリックする。
    * 同じ数式をコピーする。
    * ホットキーを押す。
* 設定により、有効数字を考慮した計算が可能です（既定では無効です）。
* 数式の先頭に"[]"で括って単位を指定することで、計算結果の単位を指定できます。  
  `[m/s] 42.195km / (2h + 25min)`
* 一変数の方程式がコピーされた場合には、以下の要領で解を算出します。
  * 1～3次方程式に対しては代数的解法を用いて解きます。  
    `x^3 - 6x^2 + 11x - 6 = 0`
  * それ以外の方程式については、ニュートン法（式の微分に成功した場合）もしくはブレント法（式の微分に失敗した場合）を用いて、近似解を一つだけ求めます。  
    `x * sin(x) = 0.2`

## 6. Ver 2.0 の新機能 ##

#### 新しい計算機 ####
* 計算機を刷新し、2分割のメモ帳形式の計算機としました。
* 計算機は、Clapteのタスクトレイメニューから「計算機」を選択するか、もしくはClapteを多重起動することで表示できます。
* 左側のペインに計算式や方程式を入力すると、自動的に計算が実行され、右側のペインに対応する計算結果が表示されます。
* 計算機では、変数や関数を自由に定義・利用して計算できる他、連立方程式の求解等の機能を利用できます。
* 詳細については、計算機のヘルプを参照してください。

#### 分数計算 ####
* 分数で計算するモードを選択できるようにしました。
* 選択可能なモードは以下の通りです。
    * 小数モード：従前と同様、小数値で計算します。
    * 分数モード：分数を用いて、整数の範囲で計算します。計算式に小数値がある場合にも、分数に変換して計算します。但し、"5/2"等の数式で、分数の範囲では計算結果が変わらない場合には小数値まで計算を行います。
    * 自動判定：原則として分数計算を行いますが、計算式に小数値が含まれる場合には小数計算を行います。また、"5/2"等の数式で、分数の範囲では計算結果が変わらない場合にも小数値まで計算を行います。

#### 数値精度の選択 ####
* 計算に用いる数値精度を選択できるようにしました。
* 選択可能な項目は以下の通りです。
    * 通常：従前と同様の方式です。最大有効桁数は15桁で、～の範囲の数値を扱えます。double型。
    * 高精度：扱える数値の範囲は通常より狭いですが、有効桁数が大きくなります。最大有効桁数は28桁で、～の範囲の数値を扱えます。
    * 任意精度：任意の精度を指定できます。また、扱う数値の範囲にも制限がありません。
* 計算速度は、通常 > 高精度 > 任意精度となります。
