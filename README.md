## 1. Clapteの概要 ##

Clapteは、数式中の単位や有効数値を考慮できる常駐型の数式電卓です。

Clapteには、以下のような機能があります。

### 常駐クリップボード計算 ###

Clapteを起動した状態で、数式として認識可能な文字列をクリップボードにコピーすると、自動的に計算を実行してその結果をバルーン表示します。

続けて、

* バルーンをクリックする。
* 同じ数式をコピーする。
* ホットキーを押す。

のいずれかを実行することで、計算結果をクリップボードにコピーすることができます。

また、カンマや空白、スペース等で区切られた数値をクリップボードにコピーした際には、
それらの数値の個数、総和、最大値、最小値、及び平均をバルーン表示します。

### 2分割メモ帳形式の計算機 ###

Clapteのタスクトレイアイコンをダブルクリックするか、Clapteを多重起動することで、計算機を起動できます。

計算機の左側ペインに計算式や方程式を入力すると、自動的に計算が実行され、計算結果が対応する右側ペインに表示されます。

計算機では、単純な計算機能に加え、以下のような機能を利用することが出来ます。

* 定数、関数の定義と利用
* 連立方程式の求解
* 数式の変形（展開、整理、因数分解）

## 5. 特殊な機能 ##

* 有効数字の考慮

    設定により、有効数字を考慮した計算が可能です（既定では無効です）。

* 単位換算

    数式の先頭に"[]"で括って単位を指定することで、計算結果を単位換算することが出来ます。  

    `[m/s] 42.195km / (2h + 25min)`

* 計算対象として一変数の方程式を指定すると、以下の要領で解を算出します。

    * 1～3次方程式に対しては代数的解法を用いて解きます。  

        `x^3 - 6x^2 + 11x - 6 = 0`

    * それ以外の方程式については、ニュートン法（式の微分に成功した場合）もしくはブレント法（式の微分に失敗した場合）を用いて、近似解を一つだけ求めます。  

        `x * sin(x) = 0.2`

その他、詳細な使用方法についてはClapteの[wiki](https://bitbucket.org/GoodSeat/clapte/wiki/Home)をご参照ください。

#### 2025.03.30 ver2.2.1 ####
* 修正
    * mod関数は、数値化できない記号を含む場合には計算対象外とするようにした（定義にmod関数を含むユーザー定義関数(floor等)が正しく評価されないケースがあったため）。
    * 計算機において、\_inp、\_INP、\_ans、\_ANSのベクトル変数はlock関数でくるんだ値とした（計算速度向上のため）。
* 追加
    * modA関数（未評価の変数を含む場合にも整数式として評価を続行する関数で、従来のmod関数と同様の挙動）を追加した。
